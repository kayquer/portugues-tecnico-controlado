Português Técnico Controlado

Reescreve texto técnico em português do Brasil para que ele tenha uma leitura só. Tira sujeito oculto, -se apassivador, modal que é obrigação e probabilidade ao mesmo tempo, e escopo decidido por vírgula. Funciona em qualquer agente — escolha o seu abaixo.

v1.2.0 Repositório As 9 regras

Linha de comando

Claude Code

Instala como skill nativa, com as referências carregando sob demanda. É a forma completa.

git clone https://github.com/kayquer/portugues-tecnico-controlado ~/.claude/skills/portugues-tecnico-controlado

Invoque com /portugues-tecnico-controlado.

Codex · opencode · Jules · Aider

Todos leem AGENTS.md da raiz do projeto. Um arquivo, nenhuma configuração.

curl -o AGENTS.md https://raw.githubusercontent.com/kayquer/portugues-tecnico-controlado/main/dist/ptc-agents.md

Cursor

Regra em .cursor/rules/, com alwaysApply: false — só entra quando o pedido combina.

mkdir -p .cursor/rules && curl -o .cursor/rules/ptc.mdc https://raw.githubusercontent.com/kayquer/portugues-tecnico-controlado/main/dist/ptc.mdc

Gemini CLI

Lê GEMINI.md da raiz. Mesmo conteúdo do AGENTS.md.

curl -o GEMINI.md https://raw.githubusercontent.com/kayquer/portugues-tecnico-controlado/main/dist/ptc-agents.md

Colar num campo de instrução

Claude.ai

Suba como Skill, ou cole nas instruções de um Projeto. Cabe a versão completa, com exemplos e referências.

ChatGPT

Instruções de Projeto ou de um GPT. O campo de custom instructions do perfil é curto demais para as duas versões.

Perplexity

Crie um Space e cole na instrução personalizada dele.

Kimi · DeepSeek · outros

Qualquer chat com campo de instrução de sistema. Se o campo aceitar texto longo, prefira a versão completa.

Sem campo de instrução? Cole a versão curta como primeira mensagem da conversa e mande o texto na segunda. Funciona igual, só não sobrevive à próxima conversa.
